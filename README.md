# My WebOS Project 🚀

Hey! This is my personal web OS project built for Hack Club Stardance. It runs directly in the browser using HTML, CSS, and JavaScript.

## 🌟 What it does
- **Desktop Interface:** Has icons, top bar clock, dynamic wallpapers, and a greeting tag.
- **Draggable Windows:** You can open, move around, and close windows.
- **Theme Toggle:** Dark and light mode switch on the top bar.

## 📱 Built-in Apps
- **Notes:** Simple text pad for quick thoughts.
- **Calculator:** Standard math app.
- **Terminal:** Runs basic commands (`help`, `whoami`, `date`, `clear`).
- **Games:** Play Tic-Tac-Toe or Snake directly in a window.
- **Timer & Music:** Features a countdown timer and a background music player.
- **Weather:** Quick local weather display widget.

## 🛠️ How I built it
I used standard HTML for structure, custom CSS for styling and window absolute positioning, and JavaScript to handle window dragging (`mousedown`/`mousemove`), app state, and game logic.
