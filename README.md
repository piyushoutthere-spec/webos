# 💻 Web OS - Personal Interactive Portfolio & Workspace

Welcome to **Web OS**, a dynamic, web-based operating system desktop environment built with pure HTML5, CSS3, and modern JavaScript. It features an interactive windowing engine, custom theme switching, lock screen, real-time utilities, and a suite of built-in desktop applications.

---

## ✨ Features

### 🪟 Desktop Environment & Core Engine
* **Lock / Welcome Screen:** Clean welcome interface with standard system entry.
* **Top Navigation Bar:** Live clock/date, customizable "heloo" tag, and light/dark theme toggle.
* **Draggable Window Engine:** Dynamic multi-window manager supporting independent positioning, focus z-indexing, and individual close controls.
* **Dynamic Background:** Automatic wallpaper selection on system boot.
